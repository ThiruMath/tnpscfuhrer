# TNPSC Group II / IIA Syllabus — Astro site

## Run locally
1. Unzip `tnpsc-syllabus-astro-source.zip`
2. `npm install`
3. `npm run dev` → open http://localhost:4321
4. `npm run build` → static site output in `dist/` (deploy anywhere: Netlify, Vercel, GitHub Pages, S3, etc.)

## What's inside
- `/` — overview: the 3-stage pipeline + where Group II and IIA diverge
- `/exam-scheme/` — Prelims + both Mains papers as scored tables, plus the full descriptive answer pattern (Parts A/B/C) for Group II Paper II
- `/prelims-syllabus/` — Code 495, all units, Tamil + English language tracks
- `/group2a-syllabus/` — Code 583, General Studies (5 units) + General Intelligence & Reasoning
- `/group2-syllabus/` — Code 469, all 7 General Studies units with descriptive marks weightage
- `/tamil-eligibility/` — Paper I pattern + syllabus themes

Content is sourced from the official TNPSC notification PDFs you provided (Codes 495, 583, 469) plus the Tamil Eligibility Test and Question Pattern documents — all dated 2024–2025 and confirmed current against tnpsc.gov.in as of Aug 2026.
